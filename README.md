# 美化工作室 · Skin Studio v0.3

Roche 小手机插件：**多套美化并行**的对话式美化工作台。左侧边栏顶部切换「美化方案」，每个方案各自一棵 35 分支的对话树；分支代码、对话记录、导出内容彼此隔离。AI 只回该对话该部位的 CSS，写完可一键合并导出。

## 安装

小手机 → 设置 → 插件 App 管理 → 填入：

```
https://raw.githubusercontent.com/<你的账号>/skin-studio/main/manifest.json
```

## 怎么用

1. 左上角「我的美化 ▾」切换/新建**方案**：一个方案 = 一套完整美化。
2. 方案下是一棵树：`风格规划 / 线上（22）/ 线下（6）/ 全局（7）`，点哪个节点就进那个对话。
3. 描述想改什么。AI 回复正文按 Markdown 渲染，CSS 抽成卡片：
   - 每段一行（`online.bubble-me · 12 行` + 写入），可单独写入/撤销；
   - `全部写入（2）` 一次写回多段；
   - `预览本次` 只注入预览，不落库。
4. 顶栏：**提示词**（注入开关 / 参考档位 / 预设 / 体积估算）、**导出**、**关闭**。
5. 输入框左下角眼睛 = 预览；预览分四档：**聊天 / 卡片墙 / 界面 / 线下**，卡片墙里点说明条可直接跳到对应分支对话。

## 多方案

| 位置 | 行为 |
|---|---|
| 侧栏顶部 | 显示当前方案名 + 「N 个方案 · M 个分支有内容」 |
| 方案列表 | 切换、新建、重命名、复制（连同对话一起复制）、删除 |
| 数据 | 每个方案独立存 `ss.project.<pid>`，对话存 `ss.chat.<pid>.<节点>.n` |

升级到 v0.3 时，旧版（v0.2）的 35 分支与对话会**自动归入「我的美化」**，不会丢。

## 提示词按需注入（省 token）

面板顶部三组开关，**按对话各自保存**：

| 开关 | 默认 | 说明 |
|---|---|---|
| 注入钩子白名单 | 关 | 开启后把该作用域可用 class 全列给 AI，体积涨得明显 |
| 注入已有 CSS | 关 | 开启后把该部位当前代码一起发过去，便于「在此基础上改」 |
| 参考片段 | 精炼 | `不注入 / 精炼（32KB 摘要）/ 完整（小节全文）` |

面板顶部实时显示「约 X KB · 约 Yk tokens」，超过 12KB 会提示关掉完整参考或切到单部位对话。系统提示词本身不可改，但可以在末尾追加**提示词预设**（见下）。

## 提示词预设库

内置 4 条只读预设（杂志风 / 纸感 / 暗夜 / 极简），可复制后改。自定义预设支持新建、编辑、改名、删除，并可限定作用域（线上/线下/全局/全部）。每个对话在提示词面板里选一套，内容以「【自定义要求 · 名称】」追加在系统提示词末尾。

## 导出（对齐宿主自己的实现）

宿主没有 Filesystem / showSaveFilePicker / Capacitor，也没有 clipboard API；它自己的「导出布局 / 贴纸包 / 世界书」用的是 `Blob + URL.createObjectURL + <a download>`。本插件沿用同一通道，并补上宿主缺的反馈：

- 点导出 → 选作用域 → **导出结果页**：行号 + 可横滚的代码区
- 底部三通道：`复制全部`（clipboard → execCommand 兜底）、`保存为文件`（宿主同款 a[download]）、`分享`（有 `navigator.canShare` 才出现）
- 每次导出自动存一份**历史版本**（最近 10 条，单条超 120KB 只留摘要），可重新复制或删除
- 三种都失败时提示「长按选择复制」，代码区始终可选中

## 预览四档

| 档位 | 注入作用域 | 内容 |
|---|---|---|
| 聊天 | 线上 | 顶栏、时间戳、双方气泡、引用、语音条、图片、表情、Canceled Call 卡、¥1.00 转账卡、邀请卡、系统灰字、输入栏 |
| 卡片墙 | 线上 | 转账、图片/位置、语音、表情、聊天记录、邀请、通知、小票、赠送代付、消息行、翻译、引用、时间灰字各一张，说明条可点跳分支 |
| 界面 | 全局 | MESSAGES 列表页（搜索/置顶/未读/时间）、NOIR 动态流（心评转发）、桌面图标、底部导航 |
| 线下 | 线下 | Offline Mode 档案卡（NO.001 / OCT 5 · 20:15 / ARCHIVE 指标）、侧栏菜单、线下输入栏 |

基线样式（`ui/preview/baseline.css`）照宿主默认值写：气泡 18px 18px 4px、iOS 尾巴 16×14 三角、白卡细边、输入栏布局。没写美化时看着就是原版。

```

【分支】online.bubble-me
【模式】REPLACE
【CSS】
```css
…
```
【分支】online.bubble-tail
【CSS】
```css
…
```
【说明】不超过 3 行
【下一步】可选
```

正文里允许 Markdown（标题/粗体/列表/引用/行内代码/链接），CSS 仍然只从代码块里取。

## 数据

| 键 | 内容 |
|---|---|
| `ss.schema` | 架构版本（=3） |
| `ss.projects` / `ss.activeProjectId` | 方案列表与当前方案 |
| `ss.project.<pid>` | 一个方案：35 分支 + 对话树状态 + 提示词配置 |
| `ss.chat.<pid>.<nodeId>.<n>` + `ss.chat.index.<pid>.<nodeId>` | 每个对话的消息分片（50 条/片） |
| `ss.presets` | 自定义提示词预设 |
| `ss.exports` | 导出历史（最多 10 条） |
| `ss.assets` / `ss.settings` | 素材库、温度与图片开关 |

## 本地开发

```bash
npm run build                      # plugin.js（约 390KB）
npm test                           # 107 个单测
npm run e2e                        # 无头 Edge 冒烟（40 项，真实坐标点按 + 命中测试）
node scripts/kill-test-edge.mjs    # 清理卡死的测试浏览器
node scripts/shot.mjs out.png [选择器...]   # 截图自查
node scripts/gen-reference.mjs     # 重新生成参考提示词
```

本地预览：任意静态服务器打开 `dev/preview.html`（390×844 手机壳，自动挂载假宿主）。

发布：`cmd /c "set GITHUB_TOKEN=ghp_xxx&& node deploy.mjs"`。

## 已知边界

- 预览是「真实类名结构 + 宿主基线样式」，用来判断配色、字排、间距是否成立，不是像素级复刻。
- 主页/列表页部分语义类（`.profile-*`、`.conversation-item`、`.bottom-nav`）在当前宿主构建里并非都存在，命中就生效。
- 「保存为文件」能否落到手机存储取决于宿主 webview 对 `a[download]` 的处理；不行就用「复制全部」再粘进美化面板。
