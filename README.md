# 美化工作室 · Skin Studio v0.2

Roche 小手机插件：**每个部位就是一个对话**。左侧边栏是一棵树（美化 → 风格规划 / 线上 / 线下 / 全局 → 类别 → 分支），点哪个节点就进入那个对话，注入的参考提示词只属于该节点；类别级对话可以让 AI 一次写整片 CSS 并逐段写回各分支。预览与导出按 线上 / 线下 / 全局 分开。

## 安装

小手机 → 设置 → 插件 App 管理 → 填入：

```
https://raw.githubusercontent.com/<你的账号>/skin-studio/main/manifest.json
```

## 怎么用

1. 左侧选节点（如「线上 → 气泡 → 我方气泡」），中间就是该部位的专属对话。
2. 描述想改什么。分支节点只注入这一个部位的参考；「线上」这种作用域节点会注入全部线上部位，并允许多段输出。
3. AI 回复里的 CSS 是一张卡：
   - 每段一行（`online.bubble-me · 12 行` + 写入按钮），可单独写入 / 撤销；
   - `全部写入（N）` 一次写回各分支；
   - `预览本次` 只把这条回复注入预览，不落库。
4. 顶栏三个入口：**提示词**（看当前对话注入了什么、切精炼/完整参考、开关分支）、**导出**（线上/线下/全局/全部）、**关闭**。
5. 输入框左下角眼睛 = 预览当前作用域；预览顶部分段可切 线上 / 线下 / 全局。

## 对话树（35 个分支）

```
美化
├─ 风格规划（定设计语言 / 令牌 / 验收清单，不直接产出部位 CSS）
├─ 线上（22）令牌 / 聊天背景 / 顶栏 / 气泡（我方·对方·尾巴）/ 内容（引用·时间·翻译·消息行）/ 输入（输入栏·加号面板）/ 卡片（转账·图片位置·语音·表情包·聊天记录·邀请·通知·赠送代付·小票）/ 浮层与搜索
├─ 线下（6）令牌 / 卡片令牌 / 卡片外观 / 卡片正文 / 侧栏 / 表单
└─ 全局（7）令牌 / 桌面 / 动态 / 列表 / 导航 / 弹窗 / 字体滚动条
```

## 提示词怎么来

`scripts/gen-reference.mjs` 把《全部 css 整理版》去空行、按小节切开，生成 `src/core/reference.generated.js`：

- `SECTIONS`：小节全文（约 87KB），只在切「完整参考」时按需拼接；
- `CONDENSED`：按分支从全文里挑出的典型规则（约 32KB），默认注入；
- `SECTION_BRANCHES`：小节 ↔ 分支的对应表。

重新生成：`node scripts/gen-reference.mjs [整理版路径]`

## AI 输出协议（v2，支持多段）

```
【判断】一句话
【分支】online.bubble-me
【模式】REPLACE
【CSS】
```css
…
```
【分支】online.bubble-tail
【CSS】
```css
…
```
【说明】不超过 3 行
【下一步】可选
```

单段回复也兼容；每段只看自己那段的 `【模式】`。缺代码块时整条按聊天渲染。

## 三条硬规则

1. **气泡只改配色与字排**：圆角、尾巴形状、头像尺寸与间距归「聊天外观」设置，插件不覆盖；改气泡底色必须同步尾巴三角色（lint 会提醒）。
2. **图片只走外链**：素材库存 URL，写成 `var(--ss-img-名字)`，不内嵌 base64。
3. **预览基线对齐宿主**：`src/ui/preview/baseline.css` 抄了宿主默认值（气泡 18px/4px、iOS 尾巴 16×14 三角、卡片圆角），没写美化时看着就是原版。

## 数据

| 键 | 内容 |
|---|---|
| `ss.schema` | 架构版本（=2，不匹配会清空旧数据） |
| `ss.branches` | 35 个分支的 CSS / 开关 / 历史 |
| `ss.chat.<节点id>.<n>` + `ss.chat.index.<节点id>` | 每个对话的消息分片（每 50 条一片） |
| `ss.nodes` | 折叠状态、精炼/完整参考 |
| `ss.assets` | 素材（只有链接与元数据） |
| `ss.settings` | 当前节点、温度、临时应用等 |

> v0.1.x 的数据不兼容：首次启动会清空并在 toast 里提示一次。

## 本地开发

```bash
npm run build                      # 产出 plugin.js（约 305KB）
npm test                           # 75 个单测
npm run e2e                        # 无头 Edge 冒烟（37 项，真实坐标点按 + 命中测试）
node scripts/kill-test-edge.mjs    # 清理卡死的测试浏览器
node scripts/gen-reference.mjs     # 重新生成参考提示词
```

本地预览：任意静态服务器打开 `dev/preview.html`（390×844 手机壳，会自动挂载）。

发布：`cmd /c "set GITHUB_TOKEN=ghp_xxx&& node deploy.mjs"`（令牌只走环境变量）。

## 已知边界

- 预览是「真实类名结构 + 宿主基线样式」，不是像素级复刻整个 12MB 应用；用来判断配色、字排、间距是否成立。
- 主页/列表页的部分语义类（`.profile-*`、`.conversation-item`、`.bottom-nav`）在当前宿主构建里并非都存在，命中就生效。
- 素材跨域时取色会失败，插件降级为手动选色，不报错。
