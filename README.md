# 美化工作室 · Skin Studio

Roche 小手机插件：用 AI 对话的方式生产美化 CSS。白色全屏界面，每个对话（项目）下按「作用域 → 部位」拆成 35 个分支，选哪个分支就只改那一块，最后合并导出一份可直接贴进美化面板的 `.css`。

## 安装

小手机 → 设置 → 插件 App 管理 → 填入：

```
https://raw.githubusercontent.com/<你的账号>/skin-studio/main/manifest.json
```

（跑一次 `node deploy.mjs` 会自动把 manifest 里的账号改对）

## 怎么用

1. 打开「美化」App，底部选作用域（线上 / 全局 / 线下）和部位（我方气泡、引用、转账卡…）。
2. 描述想要的效果，或用素材库里的生成器一键插入片段。
3. AI 回复里的 CSS 默认折叠，展开后有：
   - `预览本次`：只把这条回复注入预览，不写库；
   - `写入分支`：REPLACE 覆盖 / APPEND 追加，可撤销。
4. 左下角眼睛打开全屏预览，合并当前对话全部启用分支；顶部 chip 可单独关掉某个分支。
5. `···` → 导出 CSS，得到 `对话名-YYYYMMDD-HHmm.css`。

## 分支（35）

- **线上 22**：令牌、聊天背景（默认关闭）、顶栏、消息行（只读说明位）、我方气泡、对方气泡、尾巴、引用、时间与灰字、输入栏、`+` 面板、转账、图片与位置、语音、表情包、聊天记录、邀请、通知、赠送代付、小票弹窗、翻译、浮层
- **全局 7**：令牌、桌面图标、动态流、列表、底部导航、弹窗空状态、字体滚动条
- **线下 6**：令牌、卡片令牌、卡片外观、卡片正文、侧栏、子面板表单

## 两条硬规则

1. **气泡只改配色与字排**：圆角、尾巴形状、头像尺寸、头像↔气泡间距都是「聊天外观」设置里的内联值，插件不覆盖；改气泡底色时必须同时给尾巴三角颜色，否则 iOS 尾巴会脱色（lint 会提醒）。
2. **图片只走外链**：素材库里存 URL，写成 `var(--ss-img-名字)`；不内嵌 base64。

## AI 输出协议

AI 必须按下面格式回复，插件只取代码块：

```
【判断】一句话
【分支】online.bubble-me
【模式】REPLACE 或 APPEND
【CSS】
```css
...
```
【说明】不超过 3 行
【下一步】可选
```

缺字段时回落到「当前选中分支 + REPLACE」，并标记「格式不完整」。

## 临时应用到宿主

宿主没有公开的 CSS 注入接口，所以没有「写进美化面板」的能力。插件提供一个**临时**开关：往 `document.head` 插一个 `style#skin-studio-live`，立刻看到真实页面效果，随时可撤销；不落盘，重启失效。

## 数据

全部走 `roche.storage`（插件私有，卸载插件会清理）：

| 键 | 内容 |
|---|---|
| `ss.projects` | 对话摘要列表 |
| `ss.project.<id>` | 单个对话（含 35 个分支的 CSS） |
| `ss.messages.<id>.<n>` | 消息分片，每 50 条一片 |
| `ss.msgindex.<id>` | 分片索引 |
| `ss.assets` | 素材（只有链接与元数据） |
| `ss.settings` | temperature、上次打开的对话等 |

## 本地开发

```bash
npm install          # 可选：没装也能复用 focus-companion 的 esbuild
npm run build        # 产出 plugin.js
npm test             # 48 个单元测试（协议 / lint / 导出 / 存储 / 素材 / 生成器）
npm run e2e          # 无头 Edge 冒烟测试（15 项）
node dev/preview.html   # 用任意静态服务器打开，390×844 手机壳预览
```

发布：`cmd /c "set GITHUB_TOKEN=ghp_xxx&& node deploy.mjs"`（令牌只走环境变量，不写进任何文件）。

## 已知边界

- 主页/列表页的部分语义类（`.profile-*`、`.conversation-item`、`.bottom-nav` 等）在当前宿主构建里并非都存在，命中就生效，不命中不影响。
- 图片跨域时取色会失败，插件会降级为手动选色，不报错。
- 预览是手写模拟 DOM，用来判断配色与字排是否成立，不等同真机；真机差异以美化面板实际效果为准。
